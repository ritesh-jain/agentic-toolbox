# Agent Repositories

Curated list of public repositories containing Claude agents and similar AI agent collections.

---

## URL Format

**Always use raw GitHub URLs** for fetching markdown content. This returns clean markdown instead of HTML.

Convert GitHub blob URLs to raw URLs:
- Blob: `https://github.com/[user]/[repo]/blob/[branch]/[path]`
- Raw: `https://raw.githubusercontent.com/[user]/[repo]/[branch]/[path]`

---

## How to Search Any Agent Repository (Generic)

**Discovery Priority** (check in order):
1. **`marketplace.json`** — Machine-readable index with all agents and plugins. Found at `.claude-plugin/marketplace.json` or root.
2. **`README.md`** — Human-readable catalog organized by category with descriptions and links.
3. **`docs/reference/agents.md`** — Auto-generated roster of all agents (avelikiy pattern).
4. **GitHub Contents API** — `api.github.com/repos/[user]/[repo]/contents/[directory]` returns JSON listing of all files.
5. **GitHub Tree API** — `api.github.com/repos/[user]/[repo]/git/trees/[branch]?recursive=1` returns complete file tree in one call.

**Directory Patterns** (repos vary — check which applies):
- **Category-based**: `categories/[category]/[agent-name].md` (VoltAgent)
- **Domain-based**: `agents/[domain]/[agent-name].md` (lst97)
- **Flat root**: `agents/[agent-name].md` (avelikiy, NeoLabHQ)
- **Claude config**: `.claude/agents/[agent-name].md` (modu-ai)
- **YAML playbooks**: `playbook/[category]/[name].yml` (pied-piper — agents generated by CLI)
- **Meta-agent in root**: `agents/agent-organizer.md` (lst97 — not in category dir)

**For each agent found**:
1. Fetch the .md file using the raw URL pattern
2. Check for supporting files: `agents/_shared/`, `config/`, `docs/`
3. Extract frontmatter: name, description, mode, model, tools, maxTurns, color, skills
4. Extract system prompt body with instructions, workflows, checkpoints

### 6. sathish316/pied-piper

- **URL**: https://github.com/sathish316/pied-piper/
- **Description**: Go CLI that generates AI SubAgents from YAML playbook definitions for SDLC workflows
- **README**: `https://raw.githubusercontent.com/sathish316/pied-piper/main/README.md`
- **Playbooks**: `https://raw.githubusercontent.com/sathish316/pied-piper/main/playbook/[category]/[name].yml`

**How to Search**:
1. Fetch README for project overview and links to playbooks
2. Use GitHub Tree API (`/git/trees/main?recursive=1`) to discover full structure
3. **Playbook YAML files** are the primary agent definitions — fetch from `playbook/` directory
4. **Templates** in `config/subagent_template_*.md` show how agents are generated (Go template format)
5. **Skills** in `.claude/skills/`, `.opencode/skills/`, `.cursor/skills/`, `.codex/skills/`, `.pi/skills/` (same content, pick one)
6. **Playbook docs** in `docs/playbook/` explain multi-agent orchestration patterns (Maker-Checker, Boomerang)
7. Note: Agents are generated from YAML+templates, not stored as static .md files
